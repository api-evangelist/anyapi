# AnyAPI

A unified gateway/marketplace for scraping and data APIs. One key and one prepaid USD wallet reach hundreds of third-party data sources through a single normalized REST interface, billed pay-per-successful-request with no subscriptions. Exposes a REST API, a hosted MCP server, an llms.txt, and published agent skills.

## APIs

- **AnyAPI Gateway API** — Unified REST gateway to hundreds of normalized scraping and data APIs. Execute jobs via POST /v1/run/{sku}, browse and search the catalog, fetch SKU contracts, check wallet balance, and poll/re-read results. Also offers a hosted MCP server, llms.txt, and published agent skills. (`https://api.getanyapi.com`)

> REST API with a live public OpenAPI 3.1.0 contract at https://api.getanyapi.com/openapi.json. Hosted MCP server (Streamable HTTP, Bearer auth) at https://api.getanyapi.com/mcp. llms.txt at both site and docs level. Published agent skills via the getanyapi-com/skills repo (installable with 'npx skills add getanyapi-com/skills') and a SKILL.md agent setup file. Discovery endpoints/tools work keyless; run/balance require an AnyAPI key (X-API-Key or Authorization: Bearer). Inline keyless machine-payment via x402/MPP. Additional integration surfaces (not cataloged as APIs): TypeScript SDK (@getanyapi/sdk), Python SDK (getanyapi on PyPI), an n8n community node, and a local 'anyapi' CLI.
